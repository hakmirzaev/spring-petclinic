# Software Dependability Project – Spring Petclinic

Repository: https://github.com/hakmirzaev/spring-petclinic  
Branch: dependability-project

## Evaluation criteria checklist
1) Buildable locally + CI/CD
2) JML + OpenJML
3) Docker image on DockerHub
4) Significant test cases
5) JaCoCo coverage
6) PiTest mutation testing
7) JMH microbenchmarks
8) Security mechanisms in CI/CD
9) GitGuardian + Snyk + SonarCloud
10) No vulnerabilities reported (or fixes documented)

(Each item is worth points according to the evaluation criteria.)
